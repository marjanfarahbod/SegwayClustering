# Segway Interpretation Pipeline

This directory contains a collection of Python scripts designed to process, analyze, and assign biological meaning to genome segmentations generated by the **Segway** tool. The primary goal is to interpret the raw numerical segments from Segway by classifying them into functional categories such as **Promoter**, **Enhancer**, **Transcribed**, etc.

For background and usage of Segway itself, please see the [official Segway documentation](https://www.pmgenomics.ca/hoffmanlab/proj/segway/doc/0.2.1/).

---

## Core Functionality

The pipeline performs several key tasks:

- **Data Acquisition**: Scripts to download Segway output files, sample metadata, RNA-seq data, and corresponding ChromHMM annotations from the ENCODE portal.
- **Feature Extraction**: Parsing segtools output files (`signal_distribution.tab`, `feature_aggregation.tab`) to create feature vectors for each segment. These features are based on histone mark signals and genomic context (e.g., proximity to exons, introns, transcription start sites).
- **Machine Learning Classification**: Training a Random Forest classifier to predict biological labels from the feature vectors and applying the trained model to new segmentations.
- **Analysis and Clustering**: Clustering segments based on their features to identify patterns and relationships between different segment types across various cell types and tissues.
- **Quality Control and Validation**:
  - Comparing Segway labels against transcription data (RNA-seq) to validate functional annotations.
  - Comparing Segway labels with those from an alternative segmentation method, ChromHMM.
  - Analyzing segment length distributions and classifier prediction probabilities to assess quality and confidence.
- **Visualization**: Generating plots such as heatmaps, clustering results, transcript enrichment plots, and comparison matrices to visualize the interpretation results.

---

## Workflow / How to Use

The scripts constitute a multi-step pipeline for processing a batch of Segway segmentations. A typical workflow is as follows:

1. **Data Gathering**  
   Use scripts like `105Runs_gettingInfoFromAPI.py` and `annotation_fileDownload.py` to download the necessary Segway output files, metadata, and corresponding transcriptomics/ChromHMM data for a set of samples.

2. **Metadata Organization**  
   Run `allSamples_metaCleanUp.py` to create a unified metadata file that organizes and points to all the relevant data files for each sample.

3. **Label Prediction**  
   Use `new_apply_01.py` to apply the pre-trained classifier to the new samples. This script reads the segtools output, generates feature vectors, and produces key output files for each sample:
   - `mnemonics_v04.txt`: Maps segment numbers to their predicted biological labels.  
   - `probs_v04.csv`: Contains the prediction probabilities for each label.  

4. **Analysis and Visualization**  
   Run analysis scripts on the generated labels and probabilities to validate and explore the results:  
   - `105Runs_clusteringSegwayLabels.py`: Cluster the labels to analyze their groupings based on features and relationship to transcription.  
   - `annotation_comparison_scaled_01.py`: Compare the Segway labels with existing ChromHMM annotations to assess concordance.  
   - `transcript_plot_02.py`: Generate plots showing the enrichment of labels around genes, stratified by expression level.  
   - `classifierFeaturesHeatmap_forAll.py`: Create a global heatmap to visualize feature values across all labels and samples.  
   - `plot_pdf.py`: Generate an HTML summary page that links to all generated plots for easy browsing and review.

## Key Scripts

- `classifier_train.py`: Trains the Random Forest model for label prediction.  
- `new_apply_01.py`: Applies the trained model to new segmentation data.  
- `QC_transcriptionComparison_03.py`: Performs quality control by comparing segment labels with gene expression data.  
- `annotation_comparison_scaled_01.py`: Compares Segway and ChromHMM annotations.  
- `105Runs_clusteringSegwayLabels.py`: Performs clustering and visualization of labels and features.
