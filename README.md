## Content
The repository includes code for the paper titled "Integrative chromatin state annotation of 234 human ENCODE4 cell types using Segway reveals disease drivers" - Farahbod et al. 2023

preprint: https://www.biorxiv.org/content/10.1101/2023.10.26.564254v1
list of annotations: https://www.encodeproject.org/carts/segway-chromatin-states/


For full pipeline details, see the PDF:  
[ENCODE_code_documentation_Summ.pdf](./ENCODE_code_documentation_Summ.pdf)

### code directories

#### SegwayTrainAndRun
This directory contains scripts to automate the process of running Segway and Segtools for genome annotation. The workflow is designed to be executed on a high-performance computing (HPC) cluster using the SLURM job scheduler. The scripts are written in Python and Bash.

#### SegwayInterpretation
This directory contains a collection of Python scripts designed to process, analyze, and assign biological meaning to genome segmentations generated by the Segway tool. The primary goal is to interpret the raw numerical segments from Segway by classifying them into functional categories such as Promoter, Enhancer, Transcribed, etc.

#### transcriptomicsAnalysis
This directory contains Python scripts comparing ChromHMM and Segway annotations based on transcriptomics data.

#### enhancerAnalysis
This directory contains a collection of Python scripts for analyzing enhancer regions. The scripts focus on comparing Segway and ChromHMM annotations, utilizing Fantom5 data, and performing various analyses such as clustering, distribution analysis, and association with gene expression.
