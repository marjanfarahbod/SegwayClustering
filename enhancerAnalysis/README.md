# Enhancer Analysis

## Overview

This directory contains a collection of Python scripts for analyzing enhancer regions. The scripts focus on comparing Segway and ChromHMM annotations, utilizing Fantom5 data, and performing various analyses such as clustering, distribution analysis, and association with gene expression.

## Scripts

*   **chromHMMSegway_comparison_enhancers.py**: Compares enhancer annotations from ChromHMM and Segway.
*   **chromHMMSegway_comparison_Fantom5.py**: Compares ChromHMM and Segway annotations with Fantom5 data.
*   **Enhancer_clustering.py**: Clusters enhancer regions among the samples (not included in the paper).
*   **Enhancer_distribution.py**: Analyzes the distribution of enhancer regions (not included in the paper).
*   **enhancer_geneExpression.py**: Associates enhancer regions with gene expression data (prediction of gene expression based on the enhancer regions)
*   **Enhancer_regions.py**: Exploratory analysis for Enhancer regions in chr19 (not included in the paper)
*   **fantom5EnhancerProcessing.py**: Processes enhancer data from the Fantom5 project. 
*   **Enhancer_common.py**: Exploratory analysis (not included in the paper)

## Dependencies

The following Python libraries are required to run the scripts in this project:

*   numpy
*   pandas
*   matplotlib
*   seaborn
